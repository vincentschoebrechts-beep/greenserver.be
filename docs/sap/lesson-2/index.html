SAP from the shop floor · Lesson 2 of 10

Finding your way around SAP

The two ways of working in SAP, the transaction codes everyone uses, and the difference between master data and transactional data.

In this lesson

  • Tell SAP Fiori and SAP GUI apart.
  • Use transaction codes and the main keyboard shortcuts.
  • Distinguish master data from transactional data.

Two user interfaces

SAP Fiori is the web interface. You open the Fiori launchpad in a browser and see tiles: each tile is an app made for one task, for example confirming a production operation. Apps are role-based: a storekeeper and a planner do not see the same tiles. Fiori works on a PC and on a tablet.

SAP GUI is the classic Windows client. Here you work with transaction codes: short codes typed in the command field at the top left. Both interfaces work on the same data, and many people use both.

Transaction codes

  • Type the code and press Enter from the main menu, for example MM03 to display a material.
  • /n before the code leaves the current transaction first: /nMM03.
  • /o opens the transaction in a new session (window): /oMD04.
  • Many codes follow the pattern create, change, display: MM01, MM02, MM03 for materials, CO01, CO02, CO03 for production orders. When you only want to look, use the display code: you cannot break anything.

Two keys help everywhere in SAP GUI: F1 explains the field where the cursor is, F4 lists its possible values.

Master data and transactional data

Master data describes things that last: materials, bills of materials, routings, work centers, suppliers, equipment. It is created once and changed rarely.

Transactional data records events: a production order, a confirmation, a goods movement. Each event creates a document with a number, a date and a user. A goods movement, for example, creates a material document. Documents are not deleted: a mistake is corrected by a reversal, so the history stays complete.

Roles and authorisations

What you can see and do depends on your roles. If an app or a transaction is missing, your role probably does not include it. To learn safely, ask for display-only roles in a test or training system.

On the shop floor

An operator scans a production order at the end of an operation; the MES sends the confirmation to SAP. The production order is transactional data, the material and the routing it uses are master data, and the confirmation creates a new document that anyone with the right role can display.

Key points

  • Fiori: web apps by role. SAP GUI: classic client with transaction codes.
  • /n opens a code in the same window, /o in a new one; 01, 02, 03 often mean create, change, display.
  • F1 explains a field, F4 lists its values.
  • Master data lasts; transactional data records events in numbered documents.
