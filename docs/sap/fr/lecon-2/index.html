Se repérer dans SAP

Les deux façons de travailler dans SAP, les codes de transaction que tout le monde utilise, et la différence entre données de base et données de mouvement.

Dans cette leçon

  • Distinguer SAP Fiori et SAP GUI.
  • Utiliser les codes de transaction et les principaux raccourcis clavier.
  • Distinguer données de base et données de mouvement.

Deux interfaces

SAP Fiori est l'interface web. On ouvre le launchpad Fiori dans un navigateur et on voit des tuiles : chaque tuile est une application faite pour une tâche, par exemple confirmer une opération de fabrication. Les applications dépendent du rôle : un magasinier et un planificateur ne voient pas les mêmes tuiles. Fiori fonctionne sur PC comme sur tablette.

SAP GUI est le client Windows classique. On y travaille avec des codes de transaction : des codes courts tapés dans le champ de commande, en haut à gauche. Les deux interfaces travaillent sur les mêmes données, et beaucoup de gens utilisent les deux.

Les codes de transaction

  • Depuis le menu principal, tapez le code puis Entrée, par exemple MM03 pour afficher un article.
  • /n devant le code quitte d'abord la transaction en cours : /nMM03.
  • /o ouvre la transaction dans une nouvelle session (fenêtre) : /oMD04.
  • Beaucoup de codes suivent le schéma créer, modifier, afficher : MM01, MM02, MM03 pour les articles, CO01, CO02, CO03 pour les ordres de fabrication. Quand vous voulez seulement regarder, utilisez le code d'affichage : vous ne pouvez rien casser.

Deux touches aident partout dans SAP GUI : F1 explique le champ où se trouve le curseur, F4 liste ses valeurs possibles.

Données de base et données de mouvement

Les données de base décrivent ce qui dure : articles, nomenclatures, gammes, postes de travail, fournisseurs, équipements. On les crée une fois et on les modifie rarement.

Les données de mouvement enregistrent des événements : un ordre de fabrication, une confirmation, un mouvement de stock. Chaque événement crée un document avec un numéro, une date et un utilisateur. Un mouvement de stock, par exemple, crée un document article. On ne supprime pas les documents : une erreur se corrige par une annulation, et l'historique reste complet.

Rôles et autorisations

Ce que vous pouvez voir et faire dépend de vos rôles. S'il manque une application ou une transaction, votre rôle ne la contient probablement pas. Pour apprendre sans risque, demandez des rôles en affichage seul dans un système de test ou de formation.

En atelier

Un opérateur scanne un ordre de fabrication à la fin d'une opération ; le MES envoie la confirmation à SAP. L'ordre de fabrication est une donnée de mouvement, l'article et la gamme qu'il utilise sont des données de base, et la confirmation crée un nouveau document que toute personne ayant le bon rôle peut afficher.

À retenir

  • Fiori : applications web selon le rôle. SAP GUI : client classique avec des codes de transaction.
  • /n ouvre un code dans la même fenêtre, /o dans une nouvelle ; 01, 02, 03 signifient souvent créer, modifier, afficher.
  • F1 explique un champ, F4 liste ses valeurs.
  • Les données de base durent ; les données de mouvement enregistrent des événements dans des documents numérotés.
