SMTP Tester

When a PLC, a camera or a printer can't send its email, two questions come up: is the sender domain set up correctly, and can the server be reached? This page helps you answer both.

    Reading the result

    You seeWhat it means
    curl: (7) or (28)The port doesn't answer: a firewall, the wrong port, or port 25 blocked by the internet provider.
    curl: (35)The TLS handshake failed. On Windows, if the message mentions revocation, tick the matching option.
    curl: (60)The certificate doesn't match the requested name, typically when you target an IP address. Enter the server's name and put the IP in “Connect via IP”.
    curl: (67)Username or password rejected.
    530 5.7.0The server requires STARTTLS before anything is sent.
    535 5.7.139Microsoft 365: SMTP authentication is turned off for this mailbox or for the whole organisation.
    550 5.7.30Microsoft 365: password authentication is no longer accepted. You'll need OAuth or a relay.

    Ports worth knowing

    PortUsed for
    25Server-to-server delivery. Often blocked for outgoing traffic by consumer internet providers.
    587Sending from a client or device, with STARTTLS. This is Microsoft 365's port.
    465Sending with TLS from the first byte (SMTPS).
    2525A fallback port offered by some sending services, handy when 25 and 587 are filtered.
