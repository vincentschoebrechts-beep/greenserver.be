eWon Backup Cleaner

Since firmware 14.9s3 (Flexy) and 22.1s3 (Cosy), the passwords in an eWon backup are encrypted with a key unique to each device, written #_6_…. The backup can no longer be restored on another eWon. This page swaps those values for a clear password, which the target eWon encrypts again when it imports the file.

Clean a backup

Used for every “Replace” row you haven't edited by hand.
Written to the PIN line of comcfg.txt, whether it's encrypted, in clear or missing. Empty: the eWon keeps its current PIN. “Remove comcfg.txt” is ticked: the PIN lives in comcfg.txt, so it won't be written.
backup.tar becomes backup_clear.tar

Your files never leave your computer: this page reads and rewrites them locally. Nothing is sent to greenserver.be.

What gets changed

In the backupBy default
User passwords (config.txt)Replaced with the clear password. The adm user can't be removed.
SMTP, FTP, ISP, Wi-Fi, proxy, DynDNS…Replaced with the clear password. Type the real one in its row if the eWon needs it.
PIN (SIM PIN)Your PIN if you entered one, otherwise the encrypted line is removed so a wrong PIN can't lock the SIM.
VPNSecretKey (Talk2M)Line removed: the target eWon keeps its own key.
DefAdmPassLine removed: the target eWon keeps its own factory password.

Every row can be changed: replace, clear or remove the line. All other files and lines stay byte for byte as they were.

Then

  1. Restore the .tar with eBuddy or from the eWon's Backup/Restore page, or upload config.txt and comcfg.txt over FTP.
  2. Log in with adm and the password you chose, then change it from the web interface.
  3. On a new eWon, run the Talk2M wizard again.
  4. Keep the cleaned backups somewhere safe and delete them once they've been pushed: their passwords are in clear.

Background: HMS Networks, How to handle backup/restore since fwr 22.1s3 and 14.9s3 with the new #_6 key.
