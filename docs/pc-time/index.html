PC Time

Screen time for your Windows PC, just like on your phone. Only the time you actually spend using it counts.

Download on itch.io Download the zip from GitHub

Free, no account, no ads. Six languages.

What it does

It counts real use

When the mouse and keyboard stay still for a few minutes, the counter pauses. A coffee break doesn't inflate your day.

It shows the trend

Today's time, an hour-by-hour chart, the last seven days and a history of the last twelve months, which you can export to CSV.

It stays out of the way

The taskbar icon shows today's time, so a glance is enough. No window to open.

It tells no one

Everything stays on your PC, with automatic backups. Nothing is sent over the internet: the update button just opens a web page when you click it.

Install

  1. Download PCTime.zip from itch.io or GitHub.
  2. Unzip it wherever you like.
  3. Double-click PCTime.exe. There's nothing else to install.

PC Time isn't digitally signed, so Windows may show a SmartScreen warning the first time you run it. Click “More info”, then “Run anyway”.

Updates

The “Update” button in the app, and “Check for updates” in Settings, lead to greenserver.be/update, which always points to the latest version.

Languages

English, French, Spanish, Simplified Chinese, Hindi and Arabic, with a right-to-left layout for Arabic. You can switch languages in Settings.

Support the project

PC Time is free and will stay that way. If it's useful to you, the “Buy me a coffee” button in the app is always appreciated. The source code is on GitHub.
